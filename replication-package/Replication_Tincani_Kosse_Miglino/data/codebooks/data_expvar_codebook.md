# Codebook Note for `data_expvar_*` Datasets

This note documents the confidential input datasets named `data_expvar_*`, which are included in the replication package only under the journal-approved exemption described below. These files should be treated as confidential raw input data, not as publicly releasable source data.

## File Location

The datasets are stored in:

`confidential-data-not-for-publication/raw/April_survey`

## Dataset Files

- `data_expvar_nouni_nm.csv`
- `data_expvar_uni_nm.csv`
- `data_expvar_nouni_m800.csv`
- `data_expvar_nouni_m200.csv`
- `data_expvar_uni_m1000.csv`
- `data_expvar_uni_m300.csv`
- `data_expvar_nouni_mMean.csv`
- `data_expvar_uni_mMean.csv`

## General Description

These datasets contain subjective-earnings variables used in columns 3--6 of Appendix Table A40. The variables were constructed from restricted-access MinEduc data combined with survey data and author-created data manipulations. The appendix describes the conceptual construction of these variables.

Because the files are based partly on confidential MinEduc data, they are included in the replication package as confidential input data. They are provided in the `confidential-data-not-for-publication` folder following the journal-approved exemption that allowed these variables to be shared only as raw confidential inputs.

External replicators should use these files only if they have independently obtained access to the underlying restricted-access MinEduc data. The authors will share these confidential input variables with external replicators who have independently secured such access.

## Journal Exemption Context

The exemption request concerned columns 3--6 of Appendix Table A40. The subjective-earnings outcomes in those columns were constructed from restricted-access MinEduc data and the project survey, but the original construction code was not preserved. The replication package therefore provides these variables as confidential input data, with additional explanation in the appendix, README, and codebook materials.
