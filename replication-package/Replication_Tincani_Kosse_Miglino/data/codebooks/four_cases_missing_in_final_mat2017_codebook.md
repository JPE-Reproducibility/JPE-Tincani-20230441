# Codebook Note for `four_cases_missing_in_final_mat2017.dta`

This note documents the auxiliary dataset `four_cases_missing_in_final_mat2017.dta`, a small merge-support input.

## File Location

The dataset is stored in:

`confidential-data-not-for-publication/raw/High_school_registration/four_cases_missing_in_final_mat2017.dta`

## General Description

This dataset is similar in structure and content to the high school enrollment datasets. It contains student-school enrollment information used for high school registration and merge checks.

Unlike the main high school enrollment files, this dataset contains only 4 observations. It is an auxiliary dataset prepared by CEM of MinEduc to help the research team with data merges.
