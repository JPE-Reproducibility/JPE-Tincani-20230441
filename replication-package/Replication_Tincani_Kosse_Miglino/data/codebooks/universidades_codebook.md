# Codebook Note for `universidades.csv` and `universidades.dta`

This note documents the `universidades` dataset used in the replication package. The dataset lists Chilean universities and related institutional information, including institution type, name, acronym, founding year, main campus location, and other campus locations.

## File Location

The dataset is stored in:

`confidential-data-not-for-publication/raw/List_selective_colleges`

The folder contains both:

- `universidades.csv`
- `universidades.dta`

## Variables

- `id`
- `tipo`
- `nombre`
- `sigla`
- `fundacion`
- `sede`
- `otras_sedes`

## Variable Summary

- `id`: numeric identifier for the university record.
- `tipo`: type of university. Values observed in this field include `estatal`, `particular`, and `privada`.
- `nombre`: full university name.
- `sigla`: university acronym or abbreviation.
- `fundacion`: year in which the university was founded.
- `sede`: main campus or main location of the university.
- `otras_sedes`: additional campuses or locations associated with the university.
