# PACE Eligibility Criteria Variables

This file provides a compact orientation to the variables in the 2018 PACE eligibility criteria dataset. It is intended as a draft codebook note rather than official metadata.

## Variable Names

- `per_tipo_identificacion`
- `criterio_1`
- `criterio_2`
- `criterio_3`
- `mrun`
- `pro_anno_promocion1`
- `year`

## General Description

This dataset provides information for all students in PACE schools on which of the three criteria for PACE admission eligibility they satisfy. Taken together, the variables identify the student record, the relevant promotion or cohort year, and whether each student meets each of the three eligibility criteria used for PACE admissions.

## Data files
`PACEcriterios_mrun_2018` in `confidential-data-not-for-publication/raw/Postulantes Cupos Regulares` and `criterios_2018` in `confidential-data-not-for-publication/raw/Admission`
